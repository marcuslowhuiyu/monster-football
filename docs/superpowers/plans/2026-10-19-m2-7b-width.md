# M2.7b Step 1 — Width Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When their team has the ball, wide players (LW, RW, LB, RB) hold a wide channel along their touchline, so play reaches the flanks and goes out over the touchline more often.

**Architecture:** A pure `Positioning/WideChannel` helper (team frame) is used in four places: the in-possession shape (smaller ball-side shift for wide roles), winger forward runs (a lane 5 m from the touchline), support moves (full-backs become eligible; wide roles' spots clamped into their channel), and carries (no pull to the middle for wide players outside the final third). No new randomness. Spec: `docs/superpowers/specs/2026-10-19-m2-7b-width-design.md`.

**Tech Stack:** .NET 10 / C#, xUnit. `dotnet` lives at `~/.dotnet` — run `export DOTNET_ROOT=$HOME/.dotnet PATH=$HOME/.dotnet:$PATH` first in each shell.

**Conventions:** branch `feat/m2-7b-width` (already created, spec committed). Every commit builds and passes tests. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Team frame: own goal at X = 0, attacking +X, left flank +Y; Away converts with `TeamFrame.Convert` (180° rotation). Default pitch 105 × 68; `Formation433` anchors are authored on that pitch, so they are exact in tests.

```csharp
using MonsterFootball.Simulation.Core;
using MonsterFootball.Simulation.Players;

namespace MonsterFootball.Simulation.Positioning;

/// <summary>
/// The wide channel (ADR-034): when their team has the ball, wide players — LW, RW, LB, RB — stay near their own
/// touchline. Team frame: LW and LB belong to the left touchline (Y = width), RW and RB to the right one (Y = 0).
/// Roles decide, not listed positions (ADR-031).
/// </summary>
internal static class WideChannel
{
    public static bool IsWide(PlayingPosition role) =>
        role is PlayingPosition.LW or PlayingPosition.RW or PlayingPosition.LB or PlayingPosition.RB;

    /// <summary>The Y of <paramref name="role"/>'s touchline in team frame. Wide roles only.</summary>
    public static double TouchlineY(PitchGeometry pitch, PlayingPosition role) => role switch
    {
        PlayingPosition.LW or PlayingPosition.LB => pitch.Width,
        PlayingPosition.RW or PlayingPosition.RB => 0,
        _ => throw new ArgumentOutOfRangeException(nameof(role), role, "Only wide roles have a touchline."),
    };

    /// <summary>
    /// Moves <paramref name="local"/> (team frame) in Y so it is at most <paramref name="channelMetres"/> from the
    /// role's touchline. Central roles are returned unchanged.
    /// </summary>
    public static Vec2 Clamp(PitchGeometry pitch, PlayingPosition role, Vec2 local, double channelMetres)
    {
        if (!IsWide(role))
            return local;

        var touchline = TouchlineY(pitch, role);
        var y = touchline == 0 ? Math.Min(local.Y, channelMetres) : Math.Max(local.Y, touchline - channelMetres);
        return new Vec2(local.X, y);
    }
}
```
